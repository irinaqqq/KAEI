# README.md

## Описание проекта

Этот проект представляет собой веб-приложение с бэкендом на Django и фронтендом на React. Django используется для обработки запросов, управления базой данных и аутентификации, а React отвечает за пользовательский интерфейс.

## Установка и запуск

### 1. Клонирование репозитория

```sh
git clone <URL_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПРОЕКТА>
```

### 2. Настройка бэкенда (Django)

Перейдите в папку с бэкендом:

```sh
cd backend
```

#### Установка виртуального окружения и зависимостей

```sh
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
```

#### Настройка переменных окружения

Создайте файл `.env` в папке `backend` и добавьте в него необходимые переменные (например, настройки базы данных и ключи API).

#### Применение миграций и создание суперпользователя

```sh
python manage.py migrate
python manage.py createsuperuser  # По желанию
```

#### Запуск сервера

```sh
python manage.py runserver
```

### 3. Настройка фронтенда (React)

Перейдите в папку с фронтендом:

```sh
cd ../frontend
```

#### Установка зависимостей

```sh
npm install
```

#### Запуск приложения

```sh
npm start
```

### 4. Запуск проекта с Docker (опционально)

Если у вас установлен Docker, можно запустить проект с помощью `docker-compose`:

```sh
docker-compose up --build
```

## Дополнительная информация

- Бэкенд доступен по адресу: `http://127.0.0.1:8000/`
- Фронтенд доступен по адресу: `http://localhost:3000/`
- API-документация (если используется `drf-spectacular` или `drf-yasg`): `http://127.0.0.1:8000/api/schema/`

Если у вас возникли вопросы, проверьте документацию или создайте issue в репозитории. 🚀
